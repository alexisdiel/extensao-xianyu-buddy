# Xianyu Buddy — página de instalação

Página pública de instalação da extensão Xianyu Buddy, publicada pelo GitHub Pages:
https://alexisdiel.github.io/extensao-xianyu-buddy/

Com `?ref=<chave>` (ex.: `?ref=miguel`), a página avisa a extensão, depois de instalada, de quem veio a
indicação.

Os arquivos são cópia de `docs/instalar/` do repositório da extensão; edite lá e copie para cá.
